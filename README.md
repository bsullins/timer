# ttimer

Minimal Tabata timer for GitHub Pages. Pure HTML, CSS, and JS with sound/vibration cues.

## Run locally

Open [index.html](index.html) in a browser.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. In repo settings, go to Pages.
3. Set Source to `main` branch and `/root` folder.
4. Save. Your site will appear at `https://<username>.github.io/ttimer/`.
